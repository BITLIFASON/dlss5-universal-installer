# Безопасность

- Архивы из `packages` считаются неподтверждёнными, пока не записаны источник, версия и SHA-256.
- Утилита не запускает сторонние `.exe`, `.bat` или `.cmd` из архивов автоматически.
- Перед изменением игры создаётся точечная копия только заменяемых файлов.
- Неизвестные DLL не удаляются при удалении профиля.
- Права администратора не запрашиваются автоматически: сначала показывается предупреждение.
- Онлайн-игры с античитом не являются целью этой утилиты.
