# Testing

Use a local test plan for game-specific paths, baselines, and results. Personal test files belong in the ignored `local-tests/` directory and are not published.

For each game, inspect first, record a baseline without frame generation, install one verified method, repeat the same measurement, and restore the selected installation if the result is not acceptable.

Packages and manifests must come from the author’s official repository or the project’s official website. Verify the archive and extracted-file SHA-256 values before installation.
